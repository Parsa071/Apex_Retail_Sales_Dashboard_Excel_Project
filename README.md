# 📊 Apex Retail Sales Dashboard | Excel Data Analytics Project

## 📌 Project Overview

The **Apex Retail Sales Dashboard** is an interactive sales analytics dashboard built using Microsoft Excel. The dashboard provides a visual overview of retail sales performance, profitability, and sales trends across different regions, product categories, sales representatives, and payment methods.

The goal of this project is to transform raw sales data into meaningful insights that can help businesses monitor performance, identify trends, and make data-driven decisions.

## 🎯 Project Objectives

- Analyze overall retail sales and profitability.
- Compare sales performance across different regions.
- Identify top-performing sales representatives.
- Evaluate profit contribution by product category.
- Monitor sales trends over time.
- Understand customer payment method preferences.
- Create an interactive dashboard for easy data exploration.

## 📈 Key Dashboard Features

### 1. KPI Metrics
The dashboard highlights key performance indicators (KPIs):

- 💰 **Total Sales:** Overall revenue generated.
- 📊 **Total Profit:** Total profit generated from sales.
- 📦 **Total Quantity Sold:** Total units sold.

### 2. Sales by Region
A column chart comparing sales performance across four regions:
- East
- North
- South
- West

### 3. Top 5 Salespersons
A horizontal bar chart highlighting the top five sales representatives based on sales performance.

### 4. Profit by Category
A pie chart showing the distribution of profit across different product categories.

### 5. Sales Trend
A line chart illustrating sales performance over time to help identify fluctuations and trends.

### 6. Quantity by Payment Method
A column chart comparing the quantity of products sold through different payment methods:
- 💳 Card
- 💵 Cash
- 🌐 Online

## 🎛️ Interactive Dashboard Features

The dashboard includes interactive Excel slicers that allow users to filter the data by:

- 🌍 **Region:** East, North, South, and West.
- 💳 **Payment Method:** Card, Cash, and Online.
- 🛍️ **Category:** Clothing, Electronics, Furniture, Home Decor, Others, and Sports.

These filters allow users to explore different segments of the sales data and analyze performance based on their selected criteria.
